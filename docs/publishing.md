# 弈眼上线应用商店分析与限制说明

> 基于 0.0.35 代码状态（2026-09）。结论：**可以上架，但没有"直接提交就能过"的路径**，
> 存在合规硬性项、功能定位风险、资质与技术要求三层限制。最务实的发行方式仍是
> GitHub/网盘分发 APK（无审核、无资质要求，README 已含安装指引）。

## 一、开源合规（硬性）

APK 内包含两个 GPL 家族组件，决定了一旦上架就必须整体开源：

| 组件 | 来源与许可 | 约束 |
|---|---|---|
| Pikafish 引擎 | 官方 GPLv3，经 JNI 链接进 App（`EngineHelper` + `cpp/pikafish_jni.cpp`） | 组合作品需以 GPL 兼容方式发布：保留声明、附源码链接、注明修改 |
| 识别模型 | `middle.onnx` 源自 VinXiangQi（GPLv3）；`yolov11.onnx` 源自 public-XiangQi（GPLv3） | 模型派生自 GPL 项目，仓库文件头已注明致谢，上架时同步保留 |

合规要点：

- 项目本身已在 GitHub 开源（满足 GPL 透明要求），仓库根目录保留 `LICENSE`、
  `THIRD_PARTY_NOTICES.md`，应用"关于"页建议加一页开源致谢；
- 若将来想**闭源商业化**，这套组合走不通——需更换引擎授权（如自研或商业许可引擎）
  与非 GPL 派生模型；
- chessdb.cn 为免费公益接口：非商业使用没问题，App 商业化后高频调用建议征得站长
  同意或自建云库服务。

## 二、功能定位（最大的审核风险）

"截屏 → 识别 → 实时出招"的形态在审核方眼中即**对局辅助/外挂**：

| 渠道 | 风险 |
|---|---|
| Google Play | 政策明确禁止"协助在线游戏作弊"类应用，实时对局辅助工具历来是清理对象；大概率被拒，或上架后被下架 |
| 国内商店（华为/小米/OV/应用宝） | 审核依据截图/视频判断功能，"实时提示走法"易被判违规辅助；在线棋类平台（如腾讯系）对第三方辅助的投诉是下架常见来源 |

**降低风险的定位调整**（话术与默认场景，不改变工具能力）：

- 商店文案与产品界面往"**棋局复盘 / 训练研究工具**"靠：强调识别局面、给出参考着法、
  复盘分析；弱化/去掉"对局中实时提示"的宣传；
- 同类"象棋复盘助手"在国内商店可以正常存在，区别在定位与使用场景；
- 需清醒认识：定位调整只降低审核风险，不改变工具性质；在线对局中使用实时引擎辅助
  在几乎所有平台都违反用户协议，封号主要来自**服务端行为统计**（走招与引擎关联度、
  应答时间分布），与客户端藏得好不好无关。

## 三、上架资质与技术要求

### 国内商店

| 项 | 说明 |
|---|---|
| 软件著作权 | 必备；普通办理数百元、1~2 个月，可加急 |
| App 备案 | 2023 年起工信部强制，通过商店提交，需企业/个人主体资质 |
| 隐私政策 + 首启弹窗 | 必须写明：截屏画面仅本地处理、不上传；对外仅发送棋局 FEN 至 chessdb.cn |
| 敏感权限用途说明 | 录屏/投影（识别棋盘）、悬浮窗（显示提示）逐项写用途 |
| targetSdk | 需跟随商店年度要求（当前 34，Play 已要求 35+，国内商店逐步跟进） |

### Google Play

| 项 | 说明 |
|---|---|
| targetSdk | 新应用要求 35+（本项目当前 34，需升级） |
| Data Safety 表单 | 如实填写：画面本地处理、无个人数据收集；chessdb 查询属对外传输需声明 |
| MediaProjection | Android 14+ 每次会话需用户现场授权（已实现 `foregroundServiceType="mediaProjection"`） |
| 功能审核 | 见第二节，政策风险最高，建议最后考虑 |

## 四、建议路线

1. **维持 GitHub/网盘 APK 分发**为默认渠道（现状即可，零门槛、零审核）；
2. 若决定进商店，按顺序执行：
   - 调整定位文案（商店截图/描述 + App 内文案 → 复盘/训练工具）；
   - 起草隐私政策与首启同意弹窗（画面仅本地处理、FEN 查询外发声明）；
   - 办软著 + App 备案；
   - 上国内一两家商店试水，Google Play 最后考虑；
3. 上线前可选增强：应用"关于"页开源致谢、免责声明（"使用本工具在线对局产生的
   一切后果由用户自负，请遵守对弈平台规则"）。

## 五、已知不会构成障碍的项

- AdMob 等广告 SDK：0.0.34 起已移除残留模板配置，无第三方 SDK 合规包袱；
- 权限面干净：0.0.34 起仅保留 INTERNET / ACCESS_NETWORK_STATE /
  FOREGROUND_SERVICE(+MEDIA_PROJECTION) / SYSTEM_ALERT_WINDOW；
- 心跳看门狗、前台服务通知等均属正常前台服务形态，非审核障碍。
